🔍 TROUBLESHOOTING

Problem: Frontend shows "Checking authentication..." forever
Solution: Ensure Auth Service and API Gateway are running
  $ curl http://localhost:3008/health
  $ curl http://localhost:3001/health

Problem: Stuck on login page after clicking login
Solution: Check browser console (F12) for errors
  - Verify API Gateway is running
  - Check Network tab for failed requests
  - Look for CORS errors

Problem: Port already in use
Solution: Kill existing node processes
  $ taskkill /F /IM node.exe
  Or use START_HERE.bat (does this automatically)

Problem: Build fails
Solution: Clean build cache
  $ cd frontend
  $ rm -rf .next
  $ npm run build
