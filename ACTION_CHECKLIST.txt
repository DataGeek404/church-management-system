## ❓ If Something Goes Wrong

**Still getting 404?**
1. Verify backend really restarted (check console)
2. Verify correct URL: `http://localhost:3001`
3. Check browser network tab for actual request
4. Clear browser cache (Ctrl+Shift+Del)

**Backend won't start?**
1. Kill all node processes: `pkill -f node`
2. Go to backend folder: `cd backend`
3. Try again: `npm run start:dev`

**Still not working?**
1. Full reset:
   ```bash
   cd backend
   rm -rf node_modules/ dist/
   npm install
   npm run start:dev
   ```
