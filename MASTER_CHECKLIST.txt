## IF SOMETHING GOES WRONG

### Backend Won't Start
```bash
pkill -f node
npm run start:dev
```

### Still Getting 404
```bash
# Complete reset
rm -rf node_modules/ dist/
npm install
npm run start:dev
```

### Browser Caching Issue
```
Ctrl+Shift+Delete (clear cache)
Or Ctrl+Shift+R (hard refresh)
```
